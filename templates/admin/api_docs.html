API Documentation

Use this base URL in your loader: {{ api_base }}

POST {{ api_base }}/api.php — Auth

Authenticate user. Returns success, message, and user (with download_url for DLL).

Content-Type: application/x-www-form-urlencoded

Parameters (one of two options):

  • Option 1: login (string), password (string), data (optional, e.g. uncracked)
  • Option 2 (HWID): login (string), hwid (string) — no password. Admin must set HWID for the user in Users → Set HWID.

Success response (200):

{
  "success": true,
  "message": "Authorization success",
  "user": {
    "id": 1,
    "username": "user1",
    "secondary_group_ids": [6],
    "subscription_expires": "2025-12-31 23:59:59",
    "download_url": "{{ base_url }}/api/download?token=..."
  }
}

Error response (200, success: false):

{
  "success": false,
  "message": "Invalid credentials",
  "user": null
}
GET {{ api_base }}/download — Download DLL

Download the active DLL. Use the download_url from the auth response (contains a short-lived token).

Parameters:

  • token (required) — from user.download_url after auth
  • pid (optional) — CS:GO process ID, for logging

Success: Binary DLL file (Content-Type: application/octet-stream).

Error: 403 JSON {"success": false, "message": "Forbidden"} or 404 if no DLL.

Loader should send User-Agent containing inject for logging. Request is logged in Injections.

Summary for loader
  1. Set API URL to {{ api_base }}/api.php.
  2. Auth: POST login + password (or login + hwid).
  3. From response take user.download_url and GET it to download the DLL.
